# Security policy

## Supported versions

Paint.with.me has no published releases yet. Only the latest commit on `main`
is supported.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately
through this repository's **Security** tab on GitHub ("Report a vulnerability").

Describe what you found, how to reproduce it, and what an attacker could obtain.

If the problem also affects the upstream project,
[paint.software](https://github.com/Univers4craft/paint.software), please report
it there as well, through that repository's Security tab.
